# LibraryH2SwaggerRecords

Full-stack library management application built with React, TypeScript, Java Spring Boot, H2 database, and Swagger API documentation.

## Features
- Book management
- Author management
- Create, edit, and delete records
- REST API integration
- Swagger API documentation
- Responsive frontend interface

## Technologies

### Frontend
- React
- TypeScript
- Axios

### Backend
- Java
- Spring Boot
- H2 Database
- Swagger

## Project Structure
- `/Frontend` – React + TypeScript client application
- `/Backend` – Spring Boot REST API

## Getting Started

### Backend
1. Open the backend project
2. Run the Spring Boot application
3. Access Swagger documentation

### Frontend
1. Navigate to the frontend folder
2. Install dependencies

```bash
npm install
```

3. Start the development server

```bash
npm run dev
```

## Purpose
This project was created as a university project for practicing full-stack development, REST APIs, and frontend-backend integration.
